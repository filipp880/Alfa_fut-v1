# Проверки реализации

Проверено 24 октября 2026 года.

## Автоматический набор

Все **29 тестов прошли** на Linux / Python 3.12.15. Контейнер ограничен двумя
CPU и 2 ГБ RAM, сеть отключена. Репозиторий монтируется только для чтения;
фикстуры и распаковка архива создаются во временных каталогах контейнера.

```bash
docker run --rm --cpus=2 --memory=2g --network=none \
  --mount type=bind,source=/absolute/repository,target=/repo,readonly \
  --entrypoint python3 alfa-agent:local /repo/tests/run_tests.py
```

Покрытие:

- определение таргета, основной метрики и фактических путей;
- сохранение ведущих нулей и нестандартных идентификаторов;
- отделение обычного признака `index` от идентификатора из шаблона;
- временные периоды и блоки уникальных timestamp;
- непересекающиеся группы и отдельная подтверждающая выборка;
- частоты категорий, обученные только на train-части;
- неизвестные категории, пропуски, безопасные числовые преобразования;
- CatBoost, LightGBM и линейные модели, включая TF-IDF;
- Macro F1, порядок вероятностей, явно заданный положительный класс;
- запрет произвольного кода и обращений к таргету в конфигурациях;
- протокол Qwen и учёт пустого ответа без двойного списания из локального счётчика;
- отсутствие ключа API в окружении ML-исполнителя;
- мягкое завершение обучения и отказ от частичного refit;
- остановка зависшего процесса и общий таймер обработки данных;
- сохранение рабочего CSV после ошибок моделей;
- воспроизводимый плоский ZIP и его настоящий сквозной запуск.

## Реальные данные

Оба публичных набора полностью загружены и обработаны в Linux-контейнерах
с лимитами 8 CPU / 32 ГБ RAM без доступа к сети. В обоих случаях завершены
поиск, подтверждение, обучение на всех строках и формирование ответа.
Метрики и параметры сохранены в `VALIDATION.md` и `validation_results.json`.

## Реальный API

Через предоставленный альтернативный шлюз проверены список моделей, короткая
генерация и структурированные исследовательские гипотезы. Подтверждён
идентификатор `qwen/qwen3.8-27b`. Полный Windows-прогон классификации выполнил
два ограниченных запроса и принял конфигурации Qwen в общий цикл экспериментов.
Ключ не сохранён в репозитории и не включён в архив.

## Границы проверки

Образ локального стенда содержит рабочий поднабор разрешённых библиотек
с закреплёнными версиями. Полный организаторский `requirements.txt` сохранён
без изменений, его установка целиком локально не проверялась.
Неизвестный образ организаторов и скрытые ответы недоступны. Отправка на
соревновательную платформу не выполнялась; дневные попытки не использованы.

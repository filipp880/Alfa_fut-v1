## Как проверена корректность

Независимый отчёт пересчитывает RMSE на исходной шкале и Macro F1 по всем классам, проверяет точные индексы, группы повторов и хронологию, фиксированные итерации confirm/refit, неизменность исходных файлов и ZIP, совпадение submission.csv с прогнозом полного refit.
Для завершённого OOF заново собирается матрица из файлов каждого worker, проверяются профили fold-train, общая ось классов, отсутствие пересечений с поисковой проверкой/confirm, параметры из поиска и фиксация весов до confirm. Все 73 набора весов пересчитываются независимым кодом. Число обучений включает завершённые OOF-fit; попытки и неуспехи записаны отдельно.
Синтетические тестовые ответы хранятся у проверяющего и не монтируются в ML-контейнер. Каждый вариант видит только собственные входы, модели и результаты.

## Ограничения

Публичные периоды уже использовались в исследованиях: это проверка регрессий и повторная оценка, а не новый слепой тест. Синтетика проверяет применимость к известной структуре зависимости, но не предсказывает баллы приватной задачи. Время зависит от соседней нагрузки; таблица не доказывает ускорение. Нулевой вес семейства — допустимый результат эксперимента.
Новые реальные ответы Qwen не запрашивались. Контракт клиента проверен 33 сценариями настоящего SDK без сети; влияние новых предложений LLM на качество этого выпуска отдельно не измерялось.

## Решение о внедрении

Ранние Ridge/LogisticRegression внедрены: отдельный синтетический тест показывает RMSE 21,045203 → 0,259924 и Macro F1 0,848755 → 0,942262. На двух публичных задачах качество сохранено. Это расширение обязательного портфеля для неизвестных задач.
OOF не дал дополнительного прироста ни в одной из четырёх задач. Он оставлен как ограниченный поисковый этап для новых задач: без прироста на отдельных проверках замороженная смесь не заменяет прежний план. Для экономии времени доступен `--no-oof`. Не следует считать факт реализации OOF доказанным улучшением качества.
Дополнительный [аудит фактических моделей](LINEAR_OOF_MODEL_AUDIT.json) проверил 59 фиксированных обучений / 67 компонентов: реальные деревья, seed, конфигурации, линейные коэффициенты и SHA-256. Новых обучений при аудите нет.
Финальный [ZIP](../dist/alfa_solution_v4_2026-10-27.zip) побайтно совпадает с кандидатом в полных прогонах; SHA-256 `ce4d46965cc4f13eae67e0eeb0033c284bf6e9e3cbe48c9782964a3d2ea15708`. Прирост на приватной платформе не обещается.

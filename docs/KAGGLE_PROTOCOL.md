# Протокол новых проверок Kaggle/AIDE

Протокол зафиксирован до обучения новых гипотез 25 октября 2026 года. Источники — передача контекста и приложенный пользователем исследовательский промпт. Завершённые ExtraTrees/Nyström/kNN не считаются новыми результатами.

## Контроль и данные

Контроль — `faedd2a`: первые восемь конфигураций текущего `Research(include_alternatives=True)`, включая ExtraTrees, с неизменным `choose_finalists` и поиском комплементов. Сохранён `dist/alfa_solution_faedd2a.zip`. Исходный requirements не меняется. Только предоставленные train/test и словарь; внешние CSV, метки, веса и новые зависимости не используются.

Регрессия: поиск 1–3 → 4, подтверждение 1–4 → 5. Классификация: те же StratifiedGroupKFold по полным признакам, с отдельными search-valid и confirm-valid; confirm исключён из поискового обучения. Период 5 и подтверждающий фолд уже исследовались раньше: это повторная оценка, не новый слепой тест.

## Новые гипотезы

1. История составной сущности по атрибутам словаря. Для каждой строки используются только более ранние периоды fold-train. Пропуск ключа запрещает совпадение. Нет глобального среднего, которое могло бы использовать будущие метки. Публикуются покрытие и неоднозначные ключи.
2. Два независимых ExtraTrees-импьютера числовых атрибутов, выбранных по описаниям. Только известные значения fold-train, другие исходные X, без target/id или исторических target-признаков. Сохраняется индикатор исходного пропуска.
3. Стандартизация и PCA связанных погодных групп по словарю; медиана/scaler/PCA обучаются только на fold-train. Компоненты добавляются к исходным признакам.
4. Direct CPU hist XGBoost: невзвешенный и inverse-square-root class weights для Macro F1; в регрессии невзвешенный. Ранняя остановка по основной метрике разрешена только на search.
5. Комбинация преобразований проверяется, только если минимум два из них отдельно улучшили метрику лучшего поискового бустинга на 0,1%. Базовый бустинг у одиночных абляций один и тот же.

Неприменимые преобразования отмечаются как пропуски проверок с причиной. Отрицательные результаты сохраняются.

## AIDE-подобная абляция

Это ограниченная проверка выбора родителя конфигурации, не воспроизведение полного AIDE. У `linear` и `tree` один исходный лучший бустинг сильного контроля, одинаковый пул атомарных изменений, шесть новых fit-попыток и два seed планировщика (42/43). Seed самой модели одинаков. Общий пул создаётся одним ограниченным Qwen-вызовом через разрешённый CONNECT-прокси и дополняется безопасным резервом. Обе политики имеют одинаковый доступ к этому пулу; дополнительных LLM-вызовов внутри политик нет.

`linear` продолжает последнюю успешную конфигурацию. `tree` возвращается к лучшей либо недоисследованной успешной ветви; обе политики имеют одинаковое ограниченное исправление ошибок. Сохраняются parent/action/config/status/metric/time/error. Равны лимиты попыток и времени, а фактическое время измеряется и может различаться. Если попытки не завершены в равном бюджете, сравнение помечается как неполное.

Нынешний `Research` после портфеля уже изменяет лучшую конфигурацию. Поэтому победа над линейной цепочкой сама по себе не доказывает превосходства над текущим AutoResearch. Дополнительно сравниваются результаты новых ветвей с сильным контролем.

## Фиксация и оценка

До подтверждения сохраняются все выбранные конфигурации, число итераций, одиночные финалисты и веса парных смесей 0,25/0,5/0,75. Подтверждение/refit не используют раннюю остановку. Для таблицы оцениваются и отвергнутые поиском одиночные новые гипотезы, но по ним нельзя задним числом менять ансамбль. Итог сравнивает одинаковую процедуру ограниченного выбора single/frozen blend.

Результаты пересчитываются из сохранённых predictions.npz. Показываются RMSE или Macro F1, абсолютное и относительное изменение против сильного контроля, время и память. Парный bootstrap групп — условная неопределённость этого фолда, не гарантия будущего сдвига и не коррекция множественного выбора. Изменения с противоречием search/confirm не объявляются устойчивыми.

До открытия подтверждения регрессии дополнительно запланирован повтор seed=43 для членов исходного и выбранного нового плана. Гиперпараметры, число итераций и веса берутся из первоначальной фиксации; меняется только seed обучения. Повтор оценивает шум обучения на том же подтверждающем периоде, а не даёт новый независимый holdout. По нему веса и гипотезы не перенастраиваются.

До открытия подтверждения классификации также назначается один повтор seed43 для членов сильного контрольного и нового зафиксированного плана. Условие, метрика, разбиение, гиперпараметры, число итераций и веса сохраняются. Эта проверка оценивает чувствительность к seed; данные confirm остаются ранее исследованными.

Контейнер study+proxy суммарно до 8 CPU и менее 32 млрд байт RAM, весь запуск задачи до 10800 секунд. Поиск резервирует последние 30% времени под подтверждение/refit. Штатные данные и успешный ZIP сохраняются. На платформу ничего не отправляется.

## Дополнительная проверка разброса истории после основного подтверждения

Основной seed42 дал history 46,63257 против сильного контроля 46,58330; заранее назначенный seed43 дал 42,39794 против 46,77019. После обнаружения этого разброса назначаются ещё два seed обучения — 44 и 45 — без изменения исходных гиперпараметров, числа итераций и разбиений. Проверяются все четыре seed 42/43/44/45, без выбора лучшего. Для диагностики заранее задаётся равновесное среднее предсказаний всех четырёх seed отдельно для истории и контроля; веса по confirm не подбираются. Это дополнительная исследовательская проверка на уже просмотренном периоде, не независимое подтверждение нового ансамбля. Её задача — отличить устойчивый эффект от удачного seed; сама по себе она не основание автоматически менять штатный поиск. Обучения выполняются после завершения классификационного стенда, без параллельного превышения CPU/RAM и без дополнительных API-запросов.

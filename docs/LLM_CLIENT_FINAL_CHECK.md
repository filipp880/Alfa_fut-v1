# Мини-отчёт: повторная проверка LLM-клиента

Проверка завершена 26 октября 2026 года, два агента вместе с ведущим.
Исследован **точный код финального ZIP**, без изменения runtime.
Подтверждённых ошибок поддерживаемого env/SDK-контракта не найдено.

## Проверенные настройки

| Параметр | Проверено |
|---|---|
| Окружение | `OPENAI_API_KEY`, `OPENAI_MODEL`, `OPENAI_BASE_URL` — как в официальном baseline.py. |
| Приоритет | Непустые model/base URL платформы сохраняются; defaults используются при отсутствии/пустом значении. |
| Default gateway | `https://api.alfahack-gateway26.ru/v1` — разрешённый альтернативный адрес из TG_INFO.txt. |
| Default model | `qwen/qwen3.8-27b`. |
| HTTP | `POST /v1/chat/completions`, Bearer-авторизация, system/user messages. |
| Генерация | temperature=0,15; max_tokens=1000; retries=0. |
| Qwen | Три thinking=false настройки и `/no_think`; для явно заданной другой модели они не добавляются. |
| Таймаут | До 35 с на сетевые операции SDK, уменьшается при исчерпании поискового времени. |
| Вызовы | До 6 по умолчанию; Research обращается на шагах 3/6/9/12/15/18 при доступном ключе/бюджете. |
| Ключ | Из env, вне ZIP и ML-worker; credentials/query/тело API-ошибки в диагностику не копируются. |

`--no-llm` в архиве по умолчанию выключен. Флаги предыдущих оффлайн-бенчмарков
не зашиты в решение: платформа запускает обычный режим с её переменными.

## Границы и итог

35 с — сетевой timeout, не жёсткий wallclock всего HTTP-запроса; общий лимит
10800 с обеспечивает watchdog решения. Локальный лимит 40000 токенов использует
оценку перед запросом и reported usage либо оценку после, поэтому не является
точной предварительной токенизацией или гарантией рублёвых расходов.
Фактические env/ключ/модель/сеть судей доступны только в их журнале;
по их краткой рекомендации нельзя доказать причину предупреждения.
